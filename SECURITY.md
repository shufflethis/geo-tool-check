# Security Policy

## Reporting a vulnerability

Please report security issues **privately** — never as a public issue:

- Preferred: [GitHub private vulnerability reporting](https://github.com/geo-tool-com/geo-tool-check/security/advisories/new)
- Alternatively: the contact listed at https://www.geo-tool.com/en/contact

You will get an acknowledgment within a few business days. Please include a
reproduction and the affected version.

## Scope

This package runs entirely on the user's machine, fetches only the URLs the
user asks it to check, has zero runtime dependencies, and sends no telemetry.
Reports about the hosted service at geo-tool.com are welcome through the same
contact and are handled by the same maintainers.

## Supported versions

The latest published version on npm receives fixes.
